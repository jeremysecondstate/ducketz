# Retired Gameplan exchange

Jeremy's October 29, 2026 direction retired Gameplan production, Gameplan Stats,
synthesis and delivery along with the Gameplan Trader. The former Atlas-plan +
Scout-plan -> Scout synthesis -> delivery handoff has no current nightly duty.
Earlier standing instructions to resume it after interruptions are superseded.

The independent 15-minute traders do not synthesize forecasts, exchange execution
ledgers or wait for a peer plan or delivery receipt. Current preparation follows
[Nightly 15-minute operations](nightly-operations.md), with each PC's own symbols,
data, model recipe, broker capacity, order identities and operating state.

Existing private exchange artifacts, receipts and compatibility code are retained
history where still present. They do not authorize new exports, reconstruction
of intentionally removed outputs or reactivation of retired exchange tasks.
The former synthesis, delivery, display and repair procedures are not part of
15-minute preparation or completion.

This retirement does not retire shared-source publication, GitHub coordination,
peer source review, or their durable queues and receipts. Those engineering
procedures remain separate from private operating data and follow the verified
installed coordination contract. No private account state, raw data, fitted model
or native task memory gains publication authority from this documentation change.
